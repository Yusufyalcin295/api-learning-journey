# API Learning Journey

This repository documents my step-by-step journey of learning APIs,
from basic HTTP concepts to building APIs with FastAPI.

## Goals
- Understand HTTP and REST fundamentals
- Learn API testing with Postman
- Consume APIs using Python
- Build my own APIs with FastAPI

## Learning Method
- Theory + practice
- Real API examples
- Errors and solutions
- Clear and simple explanations

## Learning Plan
- Day 01: HTTP & REST Basics
- Day 02: Postman – GET requests
- Day 03: Postman – POST requests
- Day 04: Python Requests
- Day 05: FastAPI Basics
